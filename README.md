📰 Fake News Detection System using Machine Learning & Streamlit
Learn how to build a Fake News Detection System from scratch using Python and Machine Learning, and deploy it as an interactive web app using Streamlit! This project walks you through the full pipeline — from text preprocessing to model deployment — to create a system that can classify news articles as real or fake.
📌 What You’ll Learn
•	🔹 Text data cleaning and preprocessing (stopword removal, stemming, etc.)
•	🔹 Feature extraction using TF-IDF Vectorizer
•	🔹 Model building and training with Scikit-learn
•	🔹 Evaluating model performance with accuracy metrics
•	🔹 Creating a live Streamlit web app for fake news classification
📊 Topics Covered
•	✅ Text preprocessing techniques
•	✅ Feature engineering for NLP tasks
•	✅ Supervised machine learning algorithms:
o	Logistic Regression
o	Naive Bayes
•	✅ Building a clean and user-friendly UI with Streamlit for real-time prediction
🚀 Tools & Libraries Used
•	Python
•	Pandas, NumPy
•	Scikit-learn
•	re, string
•	Streamlit
🎯 How It Works
1.	Input: The user enters a news headline or paragraph.
2.	Preprocessing: The text is cleaned, tokenized, and transformed using TF-IDF.
3.	Prediction: The trained ML model predicts whether the input is Real or Fake.
4.	Output: The result is displayed instantly on the web interface.
